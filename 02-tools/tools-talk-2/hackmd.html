Why Look Beyond Google Docs?

From yesterday’s survey of BTS researchers:

  • Strong disdain for mega-corps and a preference for open source
  • Worries about cost and “adoption then enshittification”
  • Frustration with tools that make it impossible to collaborate across institutions
  • Want simultaneous editing and version history

Google Docs works for a lot of people. But not every collaborator can or wants to use it.

Not anti-Google: it’s a low-barrier default. The point is to know what the options are when it doesn’t fit your team.

What Is HackMD?

  • A real-time collaborative markdown editor in the browser
  • Write on the left, see the formatted result on the right
  • Notes are plain text, so they’re easy to move, version, and sync with GitHub
  • Our working group drafted the BTS workflow map in it

Features That Help Big Teams

  • Live co-editing with everyone’s cursor visible
  • Comments and named notes inline
  • Version history to go back in time
  • Tables, images, and diagrams (Mermaid)
  • GitHub sync to push notes to a repo
  • Templates for agendas and protocols
  • Books that link notes into one guide
  • Slide mode to present straight from a note

Answers the working group’s question “can’t do private stuff without paying?”: private notes are free. The limit is the number of invited editors (3) and team size. For bigger groups, set the note’s write permission to signed-in users and share the link. Demo this live.

Alternatives

Other Ways to Write Together

Tool Best for Open source? Cost
HedgeDoc HackMD-style markdown you host yourself Yes Free (self-hosted)
CryptPad End-to-end encrypted docs, sheets, and markdown Yes Free 1 GB account; paid plans; self-host
Etherpad Lightweight real-time text editing Yes Free (self-hosted)
Proton Docs Encrypted rich-text docs that open .docx No Free with a Proton account
ONLYOFFICE / Collabora Word-like editing, often via Nextcloud Yes Free community editions; often institutional
Overleaf LaTeX manuscripts Partly Free plan: 1 collaborator per project
Word online Track changes, journal formatting No Usually institutional
Quarto + GitHub Reproducible manuscripts with code Yes Free

HedgeDoc is the open-source cousin of HackMD (they share a code history), so it’s the closest match if your institution can host it.

Which One Should My Team Use?

  • Do you need tracked changes and journal formatting? → Word, ONLYOFFICE, or Collabora
  • Is privacy essential, or are some collaborators unable to use Google? → CryptPad or Proton Docs
  • Is your team comfortable with markdown and GitHub? → HackMD or HedgeDoc
  • Are you writing a LaTeX paper? → Overleaf
  • Do you want code and text in one place? → Quarto + GitHub

Pick the tool your least technical collaborator can use.

Tips for Big Team Writing

  • Keep one source of truth: draft in one place, finalize in one place
  • Draft in HackMD, finalize elsewhere: move to Word or Quarto for journal formatting
  • Use comments for discussion, not edits on top of other people’s text
  • Record contributions as you go with CRediT
  • Put the link in every meeting agenda so nobody has to hunt for the document
